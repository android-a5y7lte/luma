Summary: Panels, launchers and overlays from other desktops
Details: Apps made for other Linux desktops can add bars, docks, launchers, wallpapers and game overlays. Each of these is granted separately; a large overlay fades whenever its app is not in use and shows the app's name, and nothing an app draws can cover the lock screen, system dialogs or Luma's own panels.
